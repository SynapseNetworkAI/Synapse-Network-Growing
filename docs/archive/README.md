# Docs Archive

This directory contains historical material that is useful for audit, comparison, or evidence, but is not the active architecture source of truth.

Current architecture starts from:

1. `../../ARCHITECTURE.md`
2. `../design-docs/system-design-principles.md`
3. `../design-docs/declarative-agent-workflow-factory.md`
4. `../design-docs/planning-lifecycle-operating-manifest.md`
5. `../design-docs/recurring-workflow-control-plane.md`

Archive layout:

1. `evidence/auto-validation/`: historical auto-validation reports.
2. `evidence/test/`: historical test reports, bugfix notes, and validation screenshots.
3. `evidence/screenshots/`: historical UI screenshots.
4. `legacy-docs/`: old design or product docs that no longer define current behavior.
5. `plans/`: old planning bundles retained for traceability.

Rules:

1. Do not treat archived files as implementation requirements.
2. Do not link archived files from README as canonical docs.
3. If an archived idea becomes current again, create or update a canonical design doc instead of editing the archived source directly.
