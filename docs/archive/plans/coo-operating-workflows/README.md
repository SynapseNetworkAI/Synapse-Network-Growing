# COO Operating Workflows

This bundle turns `Synapse-Network-Growing` from a requirement/task panel into an AI company COO system with recurring operating rhythms, event-driven loops, and role-based execution.

It now also defines:

- requirement source contracts
- approval routing and approval recommendation layers
- the split between auto approval, agent-assisted approval, and human fallback

Files in this bundle:

- `spec.md`: target operating model, workflow families, and design boundaries
- `plan.md`: phased implementation plan for recurring workflows, requirement intake, and operator loops
- `task-graph.md`: dependency ordering across workflow and governance workstreams
- `validation.md`: validation protocol for proving the operating system actually runs
